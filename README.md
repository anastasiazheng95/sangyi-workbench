# 桑怡工作台 · SANGYI

外贸业务工作台（PWA）：客户 CRM、网站优化（ChatGPT 接入）、展会管理、外贸知识库、客户留言（预留 Zoho 接入）。

## 访问地址
- GitHub Pages：`https://anastasiazheng95.github.io/sangyi-workbench/`
- 可「添加到主屏幕」以全屏 App 方式使用（PWA，支持离线缓存）。

## 本地预览
用任意静态服务器即可，例如：

```bash
python3 -m http.server 8080
```

然后打开 http://localhost:8080

## 部署
推送到本仓库 `main` 分支根目录，GitHub Pages 自动发布（Settings → Pages → Source: Deploy from a branch → main / root）。
