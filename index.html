    客户留言 · Zoho 集成

    此处预留 Zoho App 接入端口。在「设置 → 客户留言接入（Zoho）」填写组织 ID / Token / Webhook 后，客户留言将自动从 Zoho CRM 或 Zoho Desk 同步到首页指标卡与动态流。

    客户留言 · WhatsApp 集成

    WhatsApp 客户消息通过 Twilio WhatsApp API 每日自动同步到首页（无需手动）。同步由 GitHub Action 驱动：在仓库 Secrets 配置 Twilio 凭证（Account SID / Auth Token / 本机 WhatsApp 号码）后自动开启，客户来讯会出现在「客户留言」指标与今日动态。
